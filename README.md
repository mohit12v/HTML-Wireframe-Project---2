# 🚲 PURE CYCLES — Bicycle Website

This is a bicycle shopping website front-end created using HTML.

## 📌 Project Overview

This project is a simple **PURE CYCLES Bicycle Website**.
It contains a navigation menu, featured bicycle images, product categories, an embedded YouTube video, promotional content, and footer information.

## 🚀 Features

- 🚲 PURE CYCLES header and navigation menu
- 🔍 Search icon
- 🛒 Shopping cart icon
- 🖼️ Main banner image
- ⭐ Featured Bikes section
- 🔐 Security Locks category
- 🪖 Bicycle Helmets category
- 🎒 Snacks! Bags category
- 🚴 Alienation category
- ▶️ Embedded YouTube video
- 🏞️ Promotional image section
- 🛍️ Shop information in the footer
- 📩 Email input section
- 🌐 Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- YouTube iframe embed

## 🧱 Website Sections

- **Header:** Website name, navigation links, search and cart icons
- **Hero Section:** Main banner image
- **Featured Bikes:** Four bicycle images and a “VIEW ALL” button
- **Shop by Category:** Security Locks, Bicycle Helmets, Snacks! Bags, and Alienation
- **Video Section:** Embedded YouTube video
- **Promotional Section:** Large promotional image
- **Footer:** Shop, Connect, About, and Don't Miss Out sections

## ▶️ How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Make sure `index.html` and the `asset` folder are in the same project directory.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
4. Make sure the image names and paths match the HTML code.

## 📝 Notes

- An internet connection may be needed to load Font Awesome icons and the YouTube video.
- The search icon, cart icon, navigation items, “VIEW ALL” button, and email signup are visual elements only unless functionality is added.
- This project was created for HTML and CSS practice.
